CAT DECODED - Bootstrap 5 Static Website

Files:
- index.html
- assets/css/style.css
- assets/js/main.js

How to run:
Open index.html directly in a browser, or run with any simple local web server.

Notes:
- Bootstrap 5.3.3 and Bootstrap Icons load from CDN.
- Demo cat photos load from Unsplash.
- Replace demo links, thumbnails, video titles, email and YouTube URL with your real Cat Decoded data.
- Main layout:
  1. Header: logo + YouTube Channel
  2. Full-width carousel
  3. 3/4 video list (12 videos) + 1/4 sidebar
  4. Full-width banner
  5. Two-column footer
  6. Copyright bar
